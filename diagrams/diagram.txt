● OpenNCL v4.0 — Architecture Overview
  ====================================

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  PRESENTATION LAYER (C# WinUI 3)                                             │
  │                                                                              │
  │  App.xaml(.cs)                    Entry point, launches MainWindow           │
  │    │                                                                         │
  │    ├── MainWindow.xaml(.cs)       Terminal UI, ~50 built-in commands         │
  │    │                              (~390 lines)                               │
  │    ├── AiSidebar.xaml(.cs)        WebView2 AI chat panel host                │
  │    ├── DebugWindow.xaml(.cs)      Debug overlay window                       │
  │    └── Command Palette            Ctrl+Shift+P, fuzzy filter over commands   │
  │                                                                              │
  └──────────────────────────────────────┬───────────────────────────────────────┘
                                        │
                                        │  C# internal calls / WebView2 bridge
                                        ▼
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  RUNTIME BRIDGE (C#)                                                         │
  │                                                                              │
  │  PythonLauncher.cs                Python process lifecycle, async I/O        │
  │  OpenNclNative.cs                 Native kernel bridge / command dispatch    │
  │  BackendDebugHub.cs               Debug boot flow & diagnostics              │
  │  AgentLoop.cs                     Agent-based command loop                   │
  │                                                                              │
  └──────────────────────────────────────┬───────────────────────────────────────┘
                                        │
                                        │  stdin/stdout protocol + __READY__ handshake
                                        ▼
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  PYTHON BACKEND                                                              │
  │                                                                              │
  │  python/launcher.py               stdin/stdout protocol bridge               │
  │    │                                                                         │
  │    ├── kernel/openncl_kernel.py   ~42 advanced commands, fuzzy suggest,      │
  │    │                              plugin loader                              │
  │    │                                                                         │
  │    ├── plugins/                   Hot-pluggable Python commands              │
  │    │   └── example_hello.py       Example plugin (COMMAND/DESCRIPTION/run)   │
  │    │                                                                         │
  │    ├── server/openncl_server.py   Flask WebUI backend, 5 REST endpoints      │
  │    │                              Listens on http://127.0.0.1:7878           │
  │    │                                                                         │
  │    └── cli/openncl_cli.py         Standalone CLI mode (no GUI)               │
  │                                                                              │
  └──────────────────────────────────────┬───────────────────────────────────────┘
                                        │
                                        │  serves / HTTP REST
                                        ▼
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  WEB UI                                                                      │
  │                                                                              │
  │  webui/ai-sidebar.html            Self-contained AI chat, SSE streaming      │
  │                                   (~280 lines), loaded into WebView2         │
  │                                                                              │
  │  webui/standalone.html            Zero-backend HTML terminal, 30+ commands   │
  │                                   No server needed, runs in any browser      │
  │                                                                              │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  CONFIG & DATA                                                               │
  │                                                                              │
  │  config/brand.json                Brand name + custom prompt persistence     │
  │  python/config.json               Python runtime configuration               │
  │  requirements.txt                 Python package dependencies                │
  │                                                                              │
  └─────────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────────┐
  │  EXTERNAL                                                                   │
  │                                                                              │
  │  es.exe (Everything Search)        Fast file search from C# layer           │
  │                                                                              │
  └─────────────────────────────────────────────────────────────────────────────┘


  COMMUNICATION CHANNELS
  ======================

    C# ──stdin/stdout──▶ Python (launcher.py)     Simple line protocol, __READY__ handshake
    C# ──WebView2─────▶ AI Sidebar                ExecuteScriptAsync / postMessage bridge
    Python ──HTTP─────▶ Flask WebUI (:7878)       5 REST endpoints
    C# ──subprocess──▶ es.exe                     Everything search integration
    C# ──WebView2─────▶ standalone.html            Loaded for zero-backend terminal


  RUN MODES
  =========

    Desktop (WinUI 3)    │  dotnet run -c Release -r win-x64
    WebUI (:7878)        │  python server\openncl_server.py
    CLI Mode             │  python cli\openncl_cli.py
    Standalone HTML      │  Open webui\standalone.html in browser


  TECH STACK
  ==========

    .NET 10  │  WinUI 3  │  WinAppSDK 1.8  │  Python 3.11  │  Flask  │  WebView2  │  Everything
